# 処理ブロック @{ }

`@{` と `}` で囲んだ行は、キーワードがなくても処理として読まれます。
セリフのあとに代入や関数呼び出しを書きたいときに使います。

```
OnClose => {
    湊: またね。
    @{
        save.終了分 = 通算分()
        hoge_talk()
    }
}
```

セリフの直後の行は、`let` `global` `call` `if` などのキーワードで始まっていない限り、セリフの続き行として読まれます（[セリフの書き方](../basic/dialogue.md#セリフのあとに処理を書く)）。
`@{ … }` の中なら、`save.終了分 = 通算分()` や `hoge_talk()` もそのまま書けます。

## 書き方

- 行頭に `@{` を書きます。`@` と `{` の間に空白は入れません。
- 閉じるのは `}` です。全角の `｛` `｝` も使えます（`@｛ … ｝`）。全角が使えるのは処理ブロックだけで、`if` などのブロックでは使えません。
- 1行でも書けます。

```
OnBoot => {
    湊: こんにちは。
    @{ save.起動回数 += 1 }
    湊: ${save.起動回数}回目だね。
}
```

## 変数の有効範囲

処理ブロックは、新しいスコープを作りません。ブロックの外と同じ場所に書いたのと同じ扱いです。

- 外で `let` した変数を、中で書き換えられます。
- 中で `let` した変数は、ブロックを閉じたあとも使えます。
- 中に書いた `if` や `while` のブロックは、ふだんどおり自分のスコープを持ちます。

```
OnBoot => {
    let 回数 = 1
    湊: 数えるよ。
    @{
        回数 += 1
        let 合計 = 回数 * 10
    }
    湊: ${回数}回、${合計}点。
}
```

`return` `break` `continue` は、ブロックの外の文と同じように働きます。

## セリフとのつながり

ブロックの前後でセリフは切れます。同じキャラクターのセリフでも、間に `\n` は入りません。
改行したいときは、前のセリフの末尾に `\n` を書いてください。

ブロックの中にセリフを書くこともできますが、セリフと処理を分けるための書き方なので、おすすめしません。

## ブロックなしで書ける場面

`let` `global` `call` `if` などのキーワードで始まる行は、ブロックなしでもセリフが切れます。
セリフより前に書く処理も、ブロックは要りません。
迷ったら `@{ … }` で囲んでおけば確実です。

## 書き忘れたとき

`@{ … }` で囲み忘れた代入や `hoge()` の呼び出しは、セリフとして出力されます。
[構文チェッカー](../error/checker.md)が `code-in-dialogue` の warning で知らせます。

## 0.4.0 以前からの変更

0.4.0 までは、セリフの直後に `@{` で始まる行を書くと、セリフの続きとして出力されていました。
今は処理ブロックとして読まれます。構文チェッカーは、この行に `script-block-after-dialogue` の notice を出します。
