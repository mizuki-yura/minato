# コメント

## 一行コメント

`//` から行末までがコメントになります。

```
OnBoot => {
    // これはコメントです
    湊: こんにちは。
}
```

## ブロックコメント

`/*` から `*/` までがコメントになります。複数行にまたがって書けます。

```
OnBoot => {
    /*
        ここはコメントです。
        複数行書けます。
    */
    湊: こんにちは。
}
```

## トークをコメントアウトする

開発中のトークを一時的に無効にしたいときに使います。

```
/*
OnRandomTalk => {
    湊: まだ書きかけのトークです。
}
*/
```
