
# 重み（@）

同じイベントに複数のトークを定義したとき、選ばれやすさを重みで調整できます。

## 基本

`@` の後に整数を書きます。

```
OnRandomTalk @3 => {
    湊: よく選ばれるトークです。
}

OnRandomTalk @1 => {
    湊: あまり選ばれないトークです。
}
```

この例では3:1の確率で選ばれます。

## 重みなし

`@` を省略すると重みは1として扱われます。

```
OnRandomTalk => {
    湊: 重みは1です。
}

OnRandomTalk @3 => {
    湊: 重みは3です。
}
```

## 直前と同じトークは選ばれにくい

同じトークが連続して選ばれないよう、直前に選ばれたトークは避けて選択されます。
候補が1つしかない場合はそのまま選ばれます。
