# 6. 単語群

里々の単語群（`＠`）は、湊にはありません。代わりに、次の3つの方法があります。里々の単語群が持っていた「ランダムに1つ選ぶ」「重複を避ける」「条件で絞る」の機能を、どれで実現するかで選びます。

| 方法 | ランダム選択 | 重複回避 | 条件で絞る | 向く場面 |
|---|---|---|---|---|
| ① 配列 + `pick()` / `draw()` | ○ | `draw()` で一巡 | 自分で書く | 短い固定リスト。順番に出すなど自由な制御 |
| ② 同名トーク + `return` | ○ | **自動（一巡）** | **`if(...)`** | 里々の単語群に一番近い。数が多いとき |
| ③ `choose()` | 条件による2択 | — | — | 真偽で2つから選ぶだけ |

## ① 配列と pick()

里々の単語群 `＠果物` に当たるのは、配列です。単語を配列1か所にまとめ、`pick()` でランダムに1つ選びます。

<!--any OnBoot-->
```mnt
OnBoot => {
    let 果物 = ["りんご", "みかん", "ぶどう"]
    湊: ${pick(果物)}が好き。
}
```
```text
\0りんごが好き。\e
\0みかんが好き。\e
\0ぶどうが好き。\e
```

空配列を渡すと `null`（表示は空文字列）になります。**この方法には重複回避がありません**。同じ単語が続けて選ばれることもあります。

配列をその場で書いて渡すこともできます。

<!--any OnBoot-->
```mnt
OnBoot => {
    湊: ${pick(["朝", "昼", "夜"])}ですね。
}
```
```text
\0朝ですね。\e
\0昼ですね。\e
\0夜ですね。\e
```

### 重複なしで順に出す（山札）

`draw()` を使うと、一巡するまで同じ単語が出ません。1つ目に山札を置く変数、2つ目に単語群の配列を書きます。

<!--any OnBoot-->
```mnt
OnBoot => {
    湊: ${draw(save.山札, ["春", "夏", "秋", "冬"])}
}
```
```text
\0春\e
\0夏\e
\0秋\e
\0冬\e
```

`draw()` は `save.山札` から1枚引き、残りを `save.山札` に書き戻します。山札が空になると、単語群を並べ替えて補充します。補充した直後に、直前と同じ単語が続くことはありません。

`draw()` は、配列関数の中で**例外的に変数そのものを書き換えます**。1つ目には変数を書いてください（`draw(["春", "夏"])` のように配列を直接書くと、書き戻す先がないのでエラーになります）。イベントをまたいで重複を避けるには、`let` ではなく `save.…` に置きます。

同じことを `shuffle()`・`last()`・`pop()` で書くと、次のようになります。補充のタイミングなどを自分で決めたいときは、こちらを使います。

<!--any OnBoot-->
```mnt
OnBoot => {
    global save.山札 ?= []
    if (len(save.山札) == 0) {
        global save.山札 = shuffle(["春", "夏", "秋", "冬"])
    }
    湊: ${last(save.山札)}
    global save.山札 = pop(save.山札)
}
```
```text
\0春\e
\0夏\e
\0秋\e
\0冬\e
```

`shuffle()` は元の配列を変えず、並べ替えた新しい配列を返します。この書き方では、補充した直後に直前と同じ単語が出ることがあります。

### 順番に選ぶ（里々の「降順」）

里々の `＄単語群「○」の重複回避【タブ】降順` のように、順番に選びたいときは、保存した番号を使います。

<!--run OnBoot OnBoot OnBoot OnBoot OnBoot-->
```mnt
OnBoot => {
    let words = ["春", "夏", "秋", "冬"]
    global save.i ?= 0
    湊: ${words[save.i % len(words)]}
    global save.i += 1
}
```
```text
\0春\e
\0夏\e
\0秋\e
\0冬\e
\0春\e
```

### 単語の追加

里々の `（単語の追加,…）` は、配列に `push` で追加します。**`push` は元の配列を変えず、新しい配列を返す**ので、代入し直す必要があります。

<!--run OnBoot-->
```mnt
OnBoot => {
    global save.覚えた ?= []
    global save.覚えた = push(save.覚えた, "りんご")
    global save.覚えた = push(save.覚えた, "みかん")
    湊: ${join(save.覚えた, "、")}|${len(save.覚えた)}
}
```
```text
\0りんご、みかん|2\e
```

同様に `pop`、`reverse`、`unique`、`shuffle`、`delete`（マップ用）も、新しい値を返すだけで元の値は変えません。

## ② 同名トークと return

**同じ名前のトークを複数書き、`return` で文字列を返す**形です。里々の `＠` に最も近く、**一巡するまで同じものを選ばない**ことが自動で保証されます（[4. トーク](talks.md)）。

<!--any OnBoot-->
```mnt
果物 => {
    return "りんご"
}

果物 => {
    return "みかん"
}

果物 => {
    return "ぶどう"
}

OnBoot => {
    湊: ${果物()}が好き。
}
```
```text
\0りんごが好き。\e
\0みかんが好き。\e
\0ぶどうが好き。\e
```

`${果物()}` が、里々の `（果物）` に当たります。

里々の「1回のトークの中で同名の単語群を何度呼んでも、同じ単語は選ばれない」という動きも、この方法なら再現できます。

<!--anyof OnBoot-->
```mnt
色 => {
    return "赤"
}

色 => {
    return "青"
}

OnBoot => {
    湊: ${色()}と${色()}
}
```
```text
\0赤と青\e
\0青と赤\e
```

2つの候補を2回呼ぶと、必ず別々の色になります。ただし、**候補がちょうど2つのときは、最初の1周の順序が決まると、そのあとは毎回同じ順序で交互に選ばれます**（周回の境目で同じものを続けないという規則のため）。上の例では、1回の実行中は「赤と青」か「青と赤」のどちらか一方だけが繰り返されます。

### 条件で絞る

里々の `＠単語群【タブ】条件式` に当たるのは、トーク定義の `if(...)` です。

<!--run OnBoot OnRain OnBoot-->
```mnt
天気 if(save.雨) => {
    return "雨"
}

天気 if(!save.雨) => {
    return "晴れ"
}

OnBoot => {
    湊: 今日は${天気()}です。
}

OnRain => {
    global save.雨 = true
}
```
```text
\0今日は晴れです。\e
(204)
\0今日は雨です。\e
```

**すべての候補が条件で除外されると、`${…}` は空文字列になります。** 作者向けのログに通知が残ります（セリフは出力されるので、気づきにくい点に注意してください）。

### 単語の中に単語

`return` に返す文字列の中で、別の単語を呼べます。

<!--run OnBoot-->
```mnt
色 => {
    return "赤"
}

りんご => {
    return "${色()}いりんご"
}

OnBoot => {
    湊: ${りんご()}です
}
```
```text
\0赤いりんごです\e
```

### セリフを含むトークは単語群に向かない

`return` ではなく、`湊:` のセリフを書いたトークを `${…()}` で呼ぶと、スコープタグ（`\0` など）も一緒に文字列に入ってしまいます。

<!--run OnBoot-->
```mnt
挨拶 => {
    湊: こんにちは
}

OnBoot => {
    湊: 「${挨拶()}」
}
```
```text
\0「\0こんにちは」\e
```

**単語や短い文だけを返すトークは、`return "…"` で書いてください。**

## ③ choose

真偽で2つのうち1つを選ぶだけなら、`choose(条件, 真のときの値, 偽のときの値)` が使えます。里々の `（when,条件,真,偽）` に当たります。

<!--run OnBoot-->
```mnt
OnBoot => {
    湊: ${choose(true, "はい", "いいえ")}
}
```
```text
\0はい\e
```

選ばれなかった側の式は評価されません（`saori()` などの副作用がある式を書いても、実行されません）。

## 里々の単語群の細かい機能

| 里々 | 湊 |
|---|---|
| 1行が1候補 | ①なら配列の1要素、②なら1つのトーク |
| 単語群の中に `（別の単語群）` | ②の `return "${別のトーク()}"` |
| 単語の追加・削除の関数 | `push` `pop` `delete`（新しい値を返すので代入し直す） |
| 重複回避の方式の変更（無効・直前・降順・昇順） | ②は「一巡」固定。①なら `draw` の山札で一巡、ほかは自作 |

## YAYAから来た方へ

- YAYAの `名前 { "a" "b" "c" }`（複数の文字列から1つを選ぶ関数）は、②の同名トークに当たります。YAYAでは `: nonoverlap` を付けて重複を避けますが、湊の②は**常に**一巡します。
- YAYAの `--` で区切って複数の単語群を連結する書き方は、`${…}` を並べて書きます。
