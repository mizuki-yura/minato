# 1. 非互換一覧（チートシート）

里々（およびYAYA）から湊に移るときに壊れるものの一覧です。**「完全互換ではありません」**。機能ごとに、どこがどう違うのかを示します。各行の右端のリンクから、詳しい説明に移れます。

- 🔴 **黙って壊れる、または起動しない**。エラーも出ずに、文が消えたり、データが残らなかったりします。
- 🟠 **動くが結果が違う**。見た目は同じコードで、計算や改行が変わります。
- 🟡 **湊にない機能**。

本文のサンプルは、すべて実機（DLL）で動かして確認しています。

## 🔴 黙って壊れる・起動しない

| 項目 | 里々 | 湊 | 詳細 |
|---|---|---|---|
| **辞書の形式** | `＊` `＠` `＄` `＞` の辞書（`dic*.txt`） | `名前 => { … }` の `.mnt`。**機械変換はできない。全部書き直し** | [2.](minimal.md) |
| **config.toml のキャラ名** | — | 日本語のキーは**必ず引用符で囲む**。囲まないと `loadu` が失敗する | [2.](minimal.md#configtoml-キャラ名は必ず引用符で囲む) |
| **台本の文字コード** | 既定 Shift_JIS | **UTF-8（BOMなし）だけ**。Shift_JISはロード失敗、**BOM付きは先頭のトークだけ黙って壊れる** | [2.](minimal.md)、[10.](encoding.md#bom付きutf-8は使わない) |
| **変数の保存** | 変数は**すべて自動保存** | **`global save.…` と書いたものだけ**保存。`let` や `global work.…` は消える。書き忘れてもエラーは出ない | [5.](variables.md#自動保存されない) |
| **セーブデータ** | `satori_savedata.txt`（全部文字列） | `save.json`（型あり）。**引き継がれない。手動で移行**。全角数字は数値にならない | [9.](savedata.md) |
| **括弧展開 `（）`** | 変数・単語群・トーク・関数を `（）` で呼ぶ | `${…}` と `call`。**全角 `（）` はただの文字**で、そのまま表示される | [5.](variables.md)、[10.](encoding.md#里々の記号) |
| **未定義の名前** | 括弧ごとそのまま表示されるので気づける | `${未定義}` は**空文字列**（警告なし） | [5.](variables.md#未定義の変数は-null) |
| **セリフ中の `英数.英数`** | — | セリフの行頭・`${}`直後の最初の語に `.` があると、**変数参照になり、文が丸ごと消える**（`体重は57.8kgです。` など） | [14.](faq.md#1-セリフが丸ごと消える) |
| **セリフ直後の代入・関数呼び出し** | — | `x = 5` や `hello()` が、**セリフの続き行として出力される**（代入されない） | [10.](encoding.md#5-セリフの直後の行は続き行になる) |
| **半角コロンのある続き行** | — | `注意:これは…` が話者指定になり、**「注意:」が消えて改行も入らない** | [10.](encoding.md#6-半角コロンのある続き行は話者の指定になる) |
| **1行ブロック** | — | `OnBoot => { 湊: こんにちは }` は書けない（パースエラー） | [10.](encoding.md#10-1行のブロックにセリフは書けない) |
| **構文エラー** | — | 1つでもあると**ゴースト全体が読み込み失敗**。`OnBoot` でエラー表示、以降は無言 | [2.](minimal.md#エラーが出たとき) |
| **単語群 `＠`** | 専用構文 | **ない**。配列か、同名トーク + `return` | [6.](wordgroups.md) |
| **ジャンプ `＞`** | 移ったら戻らない | `call` は戻ってくる。`call` の後に `return` を書く | [4.](talks.md) |
| **選択肢 `＿`** | ラベル＝ジャンプ先が自動 | `\q[ラベル,ID]` を手書き。`OnChoiceSelect` と `call reference.0` で同じ形に | [7.](choices.md#選択肢) |
| **独自イベント** | なでられ、つつかれ、`OnSatoriLoad` など | **ない**。SSPのイベントから自作 | [3.](events.md) |
| **自動処理** | 自動ウェイト、`replace.txt`、スコープ切り替え、サーフェス戻し | **ない**。手で書くか、関数で作る | [7.](choices.md) |

## 🟠 動くが結果が違う

| 項目 | 里々 | 湊 | 詳細 |
|---|---|---|---|
| **足し算 `+`** | 数式として加算 | 文字列があると**連結**（`"1" + 2` は `12`）。`reference`・SAORI戻り値・移行した値は文字列 | [5.](variables.md#型と暗黙の型変換) |
| **大小比較** | 数式 | `<` `>` は**常に数値で比較**。文字列の辞書順比較はできない（`"a" < "b"` は偽） | [14.](faq.md#8-文字列の大小比較ができない) |
| **真偽** | 0以外が真 | `0`、空文字、`null`、空の配列・マップが偽。**`"0"` は真** | [14.](faq.md#5-0-が真になる) |
| **未設定の変数** | （変数は文字列） | `null`。**`save.n == 0` は偽**。`+= 1` は 1 になる | [5.](variables.md#未定義の変数は-null) |
| **全角の数字** | 数として計算できる | **0になる**。半角に直して数値で持つ | [14.](faq.md#7-全角の数字が-0-になる) |
| **裸の代入 `x = 5`** | すべてグローバル・保存 | `let` がなければ**起動中グローバル**（他のトークから見える・保存されない） | [5.](variables.md#裸の代入は起動中グローバルになる) |
| **`let` の範囲** | — | 宣言した `{ }` の中だけ。`if` の中で作ると外で消える | [5.](variables.md#let-の有効範囲) |
| **改行** | `＊` の中の改行は自動で `\n` | **連続したセリフ行の間だけ** `\n`。コード行・空行・`;` を挟むと入らない。ループ内は入らない | [10.](encoding.md#改行のルール) |
| **ランダムトーク** | 名前のない `＊` | `OnRandomTalk`。**起動から最短5分**。`OnMinuteChange` 駆動 | [3.](events.md#②-ランダムトーク) |
| **`OnAITalk`・`OnMinuteChange`** | 通常のイベント | **自分で定義しても呼ばれない**（湊が内部で処理） | [3.](events.md#onminutechange-と-onaitalk-は自分で定義できない) |
| **間隔の設定** | `＄喋り間隔` | `config.toml` の値は**初回だけ**。以降は `save.json` が優先 | [9.](savedata.md#configtoml-の間隔設定は-savejson-が勝つ) |
| **重複回避** | 方式を選べる | **固定**（一巡）。**2候補なら交互**。`shuffle_reset` は読まれない | [4.](talks.md) |
| **採用条件** | トーク・単語群・ジャンプに付く | **トーク定義の `if(…)` だけ**。全候補が偽なら無言（204） | [4.](talks.md) |
| **未登録の話者名** | — | エラーにならず `\0` になる | [2.](minimal.md) |
| **ゼロ除算** | — | `null`（空）+ 警告。止まらない | [5.](variables.md) |
| **マップの順序** | — | 再起動後は**キー名の辞書順**になる | [5.](variables.md#変数の存在確認と削除) |
| **SAORIの戻り** | `Result` が括弧の位置に入る | `Value0` があると **`Result` は取れない**。**1イベント10回**、5秒で打ち切り | [8.](saori.md) |
| **出力の文字** | — | Shift_JISにない文字（絵文字など）は `&#数値;` に化ける | [10.](encoding.md#出力できない文字) |
| **OnRandomTalkの記録** | — | 結果が `save.last_talk` に**自動で保存**される | [3.](events.md#湊が勝手にやること) |
| **`foreach` の1変数** | — | `foreach 配列 as v` の `v` は**添字** | [14.](faq.md#18-foreach-で要素が取れない) |
| **`$` の単独** | — | セリフや `"…"` に単独の `$` があると構文エラー。`${'$'}` と書く | [10.](encoding.md#-と--の扱い) |
| **正規表現の `\d`** | — | `"\d"` と1つ書く（`"\\d"` は一致しない） | [10.](encoding.md#バックスラッシュ) |
| **曜日** | 文字（日月火…） | `now.曜日` は数値で**0が月曜**（YAYAは0が日曜） | [14.](faq.md#17-曜日の数字が違う) |

## 🟡 湊にない機能

| 機能 | 代替 | 詳細 |
|---|---|---|
| アンカー辞書、コミュニケート（`→`）、トーク予約（`＄次のトーク`） | なし。さくらスクリプト・SSPのイベントで自作 | [11.](missing.md) |
| 辞書リロード、`＄辞書フォルダ`、マルチキャラ辞書 | `include` だけ | [11.](missing.md) |
| 手動セーブ、自動セーブ間隔、セーブデータの暗号化 | なし（保存は終了時と再読み込み時だけ） | [9.](savedata.md) |
| NOTIFY の自動保存、情報取得変数の一部（起動回数など） | 自作 | [5.](variables.md)、[11.](missing.md) |
| YAYAの `EVAL`、名前空間、関数のオプション、行単位のファイル操作 | なし | [11.](missing.md)、[付録A](yaya.md) |
| 各種の設定（呼び出し回数制限、重複回避方式など） | 固定値（[制限の一覧](missing.md#制限の一覧)） | [11.](missing.md) |

## 対応があるもの

すべてが壊れるわけではありません。次のものは、ほぼそのまま移せます。

- **SSPのイベント**（`OnBoot`、`OnClose`、`OnMouseDoubleClick`、`OnChoiceSelect` など）と `Reference`
- **さくらスクリプト**（`\s[0]`、`\w5`、`\q[…]`、`\n[half]`、`\![…]` など）。セリフの中にそのまま書ける
- **同名トークからのランダム選択**（一巡固定で、里々の「有効」に近い）
- **SAORIの利用**（呼び出し方は変わる）

次は[2. 最小ゴーストの移植](minimal.md)に進んでください。
