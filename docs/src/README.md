# 湊ドキュメント

湊（みなと）は、伺か/SSP用のSHIORIエンジンです。
Rustで実装されており、`.mnt`ファイルに書かれたスクリプトを読み込んでゴーストを動かします。

このドキュメントでは湊の使い方を説明します。

## どこから読むか

- **初めて湊を使う方**は、[湊とは](intro/what_is_minato.md)から順に読んでください。
- **里々・YAYAから移ってくる方**は、[移行ガイド](migration/index.md)から始めると、違いを先に押さえられます。
- **困ったとき**は、[エラーと対処](error/index.md)を見てください。
